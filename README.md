# CensoEscolarWeb

Aplicação web (React + Vite + Bootstrap) com dados do Censo Escolar 2025 da Paraíba.

- **Home**: carrossel de imagens e cartões de informação.
- **Instituições de Ensino**: tabela com as 10 IEs com mais matrículas totais (`qt_mat_bas`).

Os dados ficam em `src/datasets/instituicoes_ensino_pb_2025.json`.

## Projeto de extração dos dados
Repositório do CensoEscolarDataApp: **COLE_AQUI_O_LINK_DO_GITHUB_DO_CensoEscolarDataApp**

## Executar
```
npm install
npm run dev
```
